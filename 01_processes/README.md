# Мониторинг процессов Linux

Скрипт на Python для сбора информации о процессах Linux с помощью команды `ps aux` и модуля `subprocess`.

## Возможности

- Подсчёт общего количества процессов и их распределение по пользователям.
- Подсчёт суммарного использования CPU и памяти на основе статистики процессов.
- Определение процессов с максимальным использованием CPU и памяти.
- Формирование текстового отчёта с временной меткой в имени файла (`*-scan.txt`).

## Требования

- Python 3
- Linux

## Запуск

Выполните в терминале команду:

```bash
python3 main.py
```

Отчёт выводится в терминал и сохраняется в текстовый файл в текущей рабочей директории.

## Используемые технологии

- Python
- `subprocess`
- `datetime`
