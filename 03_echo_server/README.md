# Echo Server

Простой HTTP-сервер на Python с использованием стандартной библиотеки `socket`.

## Возможности

- Обработка HTTP-запросов и получение метода запроса.
- Вывод адреса и порта клиента.
- Отображение заголовков запроса в теле ответа.
- Установка HTTP-статуса через GET-параметр `status`.
- Возврат статуса `200 OK`, если параметр отсутствует или содержит некорректное значение.
- Обработка нескольких запросов без перезапуска сервера.

## Запуск

Запустить сервер из каталога задания:

```bash
python echo_server.py
```

По умолчанию сервер доступен по адресу `http://127.0.0.1:5000`.

## Примеры запросов

- `http://127.0.0.1:5000/` — ответ со статусом `200 OK`.
- `http://127.0.0.1:5000/?status=404` — ответ со статусом `404 Not Found`.
- `http://127.0.0.1:5000/?status=503` — ответ со статусом `503 Service Unavailable`.

## Запуск тестов

При запущенном сервере выполнить в другом терминале:

```bash
pytest -v
```

Хост и порт можно задать через параметры pytest:

```bash
pytest -v --host=127.0.0.1 --port=5000
```

Тесты проверяют формат ответа, заголовки, обработку HTTP-статусов, поддержку метода POST и возможность обработки нескольких запросов.

## Используемые технологии

- Python
- `socket`
- `urllib.parse`
- `http.HTTPStatus`
- `pytest`
- `requests`
