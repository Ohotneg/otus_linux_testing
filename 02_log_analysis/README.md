# Анализ логов веб-сервера

Python-скрипт для анализа access-логов веб-сервера.

## Возможности

- Подсчёт общего количества запросов и статистики по HTTP-методам.
- Поиск трёх IP-адресов с наибольшим количеством запросов.
- Вывод трёх самых долгих запросов.
- Сохранение результатов в JSON.

## Запуск

Анализ одного файла:

```bash
python analyze_logs.py access.log
```

Анализ файлов в директории:

```bash
python analyze_logs.py logs/
```

## Результат

Статистика выводится в терминал и сохраняется в JSON-файл.
